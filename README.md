# WANDER — Personal Travel Dashboard 

Интерактивный персональный дашборд для планирования путешествий по Санкт-Петербургу и Ленинградской области. 
Приложение позволяет создавать собственную карту путешествий, отмечать посещённые и любимые места, 
составлять список будущих поездок, загружать фотографии и отслеживать статистику путешествий. 
Также пользователь может узнавать актуальную погоду, время восхода и заката солнца в выбранных населённых пунктах.


Используемые API
1. Open-Meteo API — получение актуальной погоды, температуры, скорости ветра, осадков и прогноза для выбранного населённого пункта.
https://open-meteo.com/
2. Sunrise-Sunset API — получение времени восхода и заката солнца, продолжительности светового дня и периодов золотого часа (Golden Hour).
https://sunrise-sunset.org/api

Дополнительно используется OpenStreetMap + Leaflet для отображения интерактивной карты и пользовательских меток.
